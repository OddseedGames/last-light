# Последний луч · OddseedGames

[![CI and Pages](https://github.com/OddseedGames/last-light/actions/workflows/ci.yml/badge.svg)](https://github.com/OddseedGames/last-light/actions/workflows/ci.yml)

**[Играть в браузере](https://oddseedgames.github.io/last-light/)** · **[Скачать ZIP для игры без интернета](https://oddseedgames.github.io/last-light/OddseedGames-LastLight.zip)**

Вторая учебная игра: ночной зомби-шутер с видом сверху, написанный на Rust + Macroquad. Отдельный проект, независимый от «Света до рассвета».

## Запуск

Открой `dist/play.html` двойным щелчком. Интернет и сервер не нужны. Для отправки игры есть `dist/OddseedGames-LastLight.zip`: распакуй и открой `play.html` внутри.

Нужны настольный браузер с WebGL/WebAssembly, клавиатура и мышь. Для начала нажми Enter или кнопку в игре. Звук изначально выключен, включается клавишей M.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD / стрелки | Двигаться |
| Мышь | Повернуть человека, оружие и фонарь |
| Q / E | Вращать фонарь без мыши; движение мыши возвращает прицеливание мышью |
| ЛКМ / пробел | Стрелять; можно удерживать |
| R | Перезарядить дробовик |
| Escape / P | Пауза |
| Enter | Начать, продолжить или повторить после поражения |
| N в паузе | Начать новую партию |
| M | Включить / выключить звук |

## Правила

Зомби появляются за границами игрового поля со всех четырёх сторон и идут к человеку. В темноте они полностью скрыты. Фонарь поворачивается вместе со стволом: конус расширяется от игрока и плавно заканчивается овальной дугой на расстоянии 313 игровых пикселей. Фонарь не освещает всё поле, заряд не расходуется.

Стрелять можно в любом направлении, но дробь поражает только зомби, чей центр находится внутри света. Каждый попавший дробиной зомби погибает сразу; залп может убить несколько целей. Всего шесть патронов, затем автоматическая перезарядка на 1,65 секунды; запас патронов бесконечный. R позволяет перезарядиться заранее. Между залпами проходит 0,52 секунды.

У человека три жизни. Укус отнимает одну жизнь и даёт 1,5 секунды защиты от повторного урона. Зомби продолжают двигаться в темноте. Напор постепенно растёт. Цель — продержаться как можно дольше и набрать больше убийств. Рекорд сохраняется до закрытия или обновления игры. При потере фокуса игра автоматически ставится на паузу.

## Разработка

Нужны Rust через rustup и Python 3. Версия Rust 1.99.1, rustfmt и цель `wasm32-unknown-unknown` закреплены в `rust-toolchain.toml`. Скрипты используют локальный Rust из `../.tools`, если он установлен, иначе из PATH. Зависимости закреплены в Cargo.lock.

После клонирования сначала загрузи зависимости: `cargo fetch --locked`. На Linux для нативных тестов и запуска нужны `pkg-config`, `libx11-dev`, `libxi-dev`, `libgl1-mesa-dev`, `libasound2-dev`. Браузерные сборка и проверки затем работают без сети.

```sh
./scripts/check.sh
./scripts/build.sh
./scripts/dev.sh
```

Сервер разработки: `http://127.0.0.1:8028`. Нативный запуск: `./scripts/run-native.sh`. На Windows команды проверок можно выполнить через Cargo, а shell-скрипты — через Git Bash. Сборка создаёт `dist/index.html` для сайта, автономный `dist/play.html`, ZIP и `dist/build.json` с SHA коммита и контрольными суммами.

## Структура и проверки

| Файл / каталог | Ответственность |
| --- | --- |
| `src/main.rs`, `src/app.rs` | Точка входа и игровой цикл |
| `src/game.rs` | Состояние партии, движение, преследование, попадания, урон, перезарядка |
| `src/lighting.rs` | Геометрия луча и проверка видимости без графического контекста |
| `src/input.rs` | Снятие ввода и отдельный тестируемый контроллер действий |
| `src/layout.rs` | Общая геометрия поля и кнопок для ввода и отрисовки |
| `src/view/world.rs`, `src/view/actors.rs` | Мир, персонажи, следы попаданий и свет |
| `src/view/hud.rs`, `src/view/overlay.rs` | Индикаторы, меню, пауза, поражение и прицел |
| `src/view/theme.rs`, `src/view/mod.rs` | Цвета, текст, камера и ограничение отрисовки полем |
| `src/ground.glsl` | Освещение асфальта с параметрами из `lighting.rs` |
| `src/audio.rs`, `src/browser.rs` | Звук и браузерный жизненный цикл |
| `tests/gameplay.rs`, `tests/input.rs` | Проверки правил и контроллера ввода без окна |
| `tests/browser/` | Проверка автономного HTML в Chromium с отключённой сетью |
| `scripts/` | Проверки, сборка WASM и упаковка HTML/ZIP |

Браузерные тесты локально:

```sh
python3 -m pip install -r tests/browser/requirements.txt
python3 -m playwright install chromium
python3 -m unittest discover -s tests/browser -v
```

`tests/browser-smoke.js` дополнительно позволяет проверить управление через `evaluate_script` Chrome DevTools MCP в открытой игре; содержимое передаётся как функция.

GitHub Actions проверяет форматирование, игровые тесты и компиляцию WASM на Linux и Windows. Затем собирает игру, проверяет содержимое HTML/ZIP и запускает браузерные тесты без сети. Только после успешных проверок `main` публикуется в GitHub Pages. Для pull request выполняются проверки и сборка. При сбое браузерных тестов CI сохраняет скриншоты и трассировки; автономная игра и ZIP доступны также в артефактах успешной сборки.

Игровые правила и отрисовка написаны на Rust. JavaScript только загружает WASM, передаёт браузерные события движку, обрабатывает полноэкранный режим и публикует статус для диагностики.

## Материалы

Учебный прототип создан с помощью ИИ: код, программная графика и синтез звуков. Ассетов из других игр нет. Звуки воспроизводимо создаются `python3 scripts/generate-audio.py`.
